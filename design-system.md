# Design System

## Purpose

This document defines the visual direction of the Steelform Engineering website.

The objective is not to create a highly designed marketing website.

The objective is to create a professional, trustworthy industrial website that:

- Generates enquiries
- Demonstrates capability
- Supports SEO
- Presents technical information clearly
- Highlights real project work

The website should feel like a credible engineering company, not a technology startup.

---

# Brand Position

## Personality

The website should feel:

- Technical
- Experienced
- Professional
- Practical
- Industrial
- Trusted
- Australian

---

## It Should Not Feel Like

- A startup
- A software company
- A marketing agency
- A consumer ecommerce store
- An overly corporate enterprise site

---

# Design Principles

## Content First

Content should be the primary focus.

Pages should be easy to scan.

Information should be structured clearly.

---

## Real Work Sells

Real projects are more valuable than marketing claims.

Prioritise:

- Project photography
- Workshop photography
- Equipment photography

Avoid:

- Generic stock photography
- Corporate office photography

---

## Mobile First

Most users will first view the website on mobile.

Layouts must function on:

- Mobile
- Tablet
- Desktop

---

## Fast Loading

Performance is a feature.

All pages should:

- Load quickly
- Optimise images
- Minimise unnecessary animations

- Strong

- Technical

# Layout

## Container Width

Desktop:

```text
1280px
```

---

## Reading Width

Content pages:

```text
700-800px
```

Maximum.


# Images

Images should prioritize:

1. Completed projects
2. Workshop operations
3. Fabrication processes
4. Equipment in service

Preferred ratio:

```text
16:9
```

Card images:

```text
4:3
```

---

# Cards

Purpose:

Display:

- Solutions
- Projects
- Articles

Style:

- White background
- Light shadow
- 12px radius
- Hover elevation

Cards should be simple and content focused.

---

# Buttons

## Primary

Purpose:

Main conversion action.

Style:

- Filled
- Dark blue
- White text

Examples:

- Request Quote
- Contact Us

---

## Secondary

Purpose:

Supporting action.

Style:

- Outline

Examples:

- View Project
- Read Article

---

# Calls To Action

Primary CTA:

Request Quote

Secondary CTA:

Speak to an Engineer

Every page should contain at least one CTA.

---

# Accessibility

Target WCAG AA compliance.

Requirements:

- Keyboard navigation
- Appropriate contrast
- Semantic headings
- Alt text for images
- Responsive layouts

---

# Development Notes

Preferred Stack:

- Next.js
- TypeScript
- Tailwind CSS
- Sanity CMS
- Vercel

Animations should be subtle.

The website should feel professional and durable rather than trendy.
