# Homepage Layout

## Purpose

The homepage is not designed to rank for every keyword.

The homepage exists to:

1. Explain what Steelform does.
2. Establish credibility.
3. Direct users to solutions.
4. Showcase recent work.
5. Generate enquiries.

---

# User Questions

The homepage should answer these questions in order:

1. What do you do?
2. Can you do what I need?
3. Have you done it before?
4. Can I trust you?
5. How do I contact you?

---

# Development Guidance

The homepage should remain relatively simple.

Avoid adding:

- Large sliders
- Rotating banners
- Excessive animations
- Complex page builders

The homepage is primarily a routing page that directs users into:

- Solution Pages
- Project Pages
- Knowledge Articles

These content types are expected to generate most organic search traffic and conversions over time.
